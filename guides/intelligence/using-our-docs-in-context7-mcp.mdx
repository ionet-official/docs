title: "Using Our Docs in Context7 MCP"
---

You can use our documentation directly inside any MCP-enabled AI agent by adding it to [Context7](https://context7.com/).

This lets AI tools and developer assistants automatically pull answers from our docs when you’re building with our platform.

## How to Add Our Docs

1. Go to [Context7](https://context7.com/).

   <img
     src="/images/docs/using-our-docs-in-context7-mcp/Context7-1.jpg"
     alt="Context7 1 Jp"
     title="Context7 1 Jp"

     style={{ width:"72%" }}
   />
2. Sign in with your GitHub account.

   <img
     src="/images/docs/using-our-docs-in-context7-mcp/Context7-2.jpg"
     alt="Context7 2 Jp"
     title="Context7 2 Jp"
     className="mx-auto"
     style={{ width:"45%" }}
   />
3. Click **“Add new source”**.

<img
  src="/images/docs/using-our-docs-in-context7-mcp/Context7-3.jpg"
  alt="Context7 3 Jp"
  title="Context7 3 Jp"

/>

 4. Enter one or more of these sources:

- GitHub repo: `https://github.com/ionet-official/iointel`
- Documentation site: `https://docs.io.net/docs/`
- API reference: `https://docs.io.net/reference/`

  <img

  />

5. Click **Scrape** to ingest the content.\
   _(You can click “Refresh” later if the docs are updated.)_

## Why Use Context7 MCP

- Makes our docs **searchable and retrievable by MCP-enabled AI agents**.
- Enables **faster development** using agents that can read our docs directly.
- Supports both **public websites** and **private GitHub repositories**.

> 📘 Tip: Want to keep your local copy of the docs fresh in Context7?
>
> Return to the [Context7 dashboard](https://context7.com/) and click **Refresh** on our sources whenever we update the docs.
