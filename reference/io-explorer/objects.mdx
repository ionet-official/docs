### Device Object

The **Device Object** defines a single computational unit within the IO Network — typically a machine or worker node equipped with one or more GPUs. It provides the fundamental structure for representing devices that contribute compute resources to the network. Each device record captures hardware specifications, performance data, connectivity status, geographic location, and compliance information.

This object is central to how the IO Network manages, monitors, and compensates devices for running distributed compute jobs. It tracks device uptime, speed metrics, SOC 2 compliance, and job-level data such as earnings, job duration, and connection stability, thus forming the foundation for analytics, reliability scoring, and marketplace operations.

</ParamField>

<ParamField path="brand_icon" type="string" required>

</ParamField>

<ParamField path="device_id" type="string" required>
  Unique identifier for your device.
</ParamField>

<ParamField path="down_percentage" type="integer" required>
  Percentage of time the device was down or unavailable.
</ParamField>

<ParamField path="download_speed_mbps" type="integer" required>
  Average download speed for this device, measured in megabits per second.
</ParamField>

<ParamField path="downtime_by_date" type="object" required>
  An object where each key is a date string (YYYY-MM-DD format) representing a specific day. 
  The value is an array of objects, each detailing downtime information for that day.

  <Expandable title="properties">
    <ParamField path="downtime_by_date.key" type="string" required>
      Format: YYYY-MM-DD —> The date the downtime occurred.
    </ParamField>

    <ParamField path="downtime_by_date.value" type="array" required>
      Each date key maps to an array of objects, where each object contains the following properties.

      <Expandable title="properties">
        <ParamField path="downtime_by_date.value.downtime" type="number" required>
          The total duration of downtime in seconds.
        </ParamField>

        <ParamField path="downtime_by_date.value.note" type="string" required>
          A note providing the downtime duration in days, hours, and minutes.
        </ParamField>
        **Example**

        ```json json
        {
          "2023-09-11": {
            "downtime": 281.508,
            "note": "down for 0 days and 0 hours and 4 minutes"
          },
          "2023-09-12": {
            "downtime": 12193.385,
            "note": "down for 0 days and 3 hours and 23 minutes"
          }
        }
        ```
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField path="hardware_name" type="string" required>
  Name of the hardware model used in the device, such as 'RTX A6000'.
</ParamField>

<ParamField path="hardware_quantity" type="integer" required>
  Number of hardware components, defined in /hardware_name, installed in the device.
</ParamField>

<ParamField path="iso2" type="string" required>
  Country ISO Code that provides the country location of the device. For example, CA for Canada.
</ParamField>

<ParamField path="jobs" type="array" required>
  An array of objects, each representing different dimensions of the job. 
  Every object in the array contains info about an aspect of the job, including duration, status, earnings, and slashed earnings.

  <Expandable title="properties">
    <ParamField path="jobs.compute_minutes_hired" type="integer" required>
      Total number of minutes a customer hired the device.
    </ParamField>

    <ParamField path="jobs.compute_minutes_served" type="integer" required>
      Total number of minutes the device was used for the job.
    </ParamField>

    <ParamField path="jobs.earned" type="integer" required>
      Total $IO earnings for the hired job.
    </ParamField>

    <ParamField path="jobs.end_time" type="datetime string" required>
      Date and time the job ended, in UTC.
    </ParamField>

    <ParamField path="jobs.for" type="string" required>
      Cluster ID.
    </ParamField>

    <ParamField path="jobs.slashed" type="integer" required>
      Total slashed earnings for the job.
    </ParamField>

    <ParamField path="jobs.start_time" type="datetime string" required>
      Date and time the job started, in UTC.
    </ParamField>

    <ParamField path="jobs.status" type="string" required>
      Status of the job.
    </ParamField>

    <ParamField path="jobs.total_hire_rate" type="integer" required>
      Amount paid to the device owner if the device performs at 100% uptime for the duration of the job.
    </ParamField>

    <ParamField path="jobs.uptime_percent" type="integer" required>
      Percent of time the device was connected.
    </ParamField>

    **Example**

    ```json
    {
      "jobs": [
        {
          "compute_minutes_hired": 300,
          "compute_minutes_served": 0,
          "earned": 0,
          "end_time": "2023-09-12 00:00:00",
          "for": "e242cd76-9e65-4de1-b3ec-1cb8b002b38d",
          "slashed": 0,
          "start_time": "2023-09-12 00:00:00",
          "status": "pending",
          "total_hire_rate": 10.8,
          "uptime_percent": 100
        }
      ]
    }
    ```
  </Expandable>
</ParamField>

<ParamField path="location_icon" type="string" required>

</ParamField>

<ParamField path="location_name" type="string" required>
